# Retail Sales Executive Dashboard

A 4-page interactive Power BI dashboard built to analyze retail sales performance, profitability, customer behavior, and executive KPIs.

## Project Highlights

- Executive Summary with KPI cards
- Product Performance Analysis
- Top 10 Products by Sales
- Bottom 10 Products by Profit
- Customer Insights Dashboard
- Geographic Sales Analysis using Maps
- Executive Insights with YoY Growth
- Interactive Slicers for Year, Region, and Category

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling (Star Schema)

## Dashboard Pages

1. Executive Summary  
2. Product Performance  
3. Customer Insights  
4. Executive Insights

## Key Measures

- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Repeat Customers
- Previous Year Sales
- YoY Growth %
